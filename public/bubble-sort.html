Bubble Sort (Ordenação por Bolha)

Complexidade Média: O(N²)

Simulação do Algoritmo

Como Funciona?

O Bubble Sort é um algoritmo de ordenação por comparação bruta. Ele percorre o array sequencialmente várias vezes. A cada passagem, compara elementos adjacentes em pares e os troca de lugar caso o primeiro elemento seja maior que o segundo. Esse processo faz com que os maiores valores flutuem gradualmente para o final da lista, como bolhas de ar subindo na água.

Análise de Complexidade (Big O)

Abaixo estão os cenários de performance do Bubble Sort tradicional. Note como ele mantém loops pesados independentemente da disposição inicial dos elementos.

Cenário Notação Big O Comportamento do Algoritmo
Pior Caso O(N²) Ocorre quando a lista de entrada está em ordem totalmente inversa.
Caso Médio O(N²) Ocorre na maioria das distribuições aleatórias de elementos.
Melhor Caso O(N²) No modelo clássico, ele roda todas as verificações mesmo se o array já estiver ordenado.
